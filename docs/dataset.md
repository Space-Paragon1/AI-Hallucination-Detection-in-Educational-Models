# Dataset Documentation

## Overview

The hallucination detection dataset covers two mathematics domains: **algebra** and **calculus**. All examples are synthetically generated and manually reviewed. Each example is a (question, model_answer) pair labeled as correct (0) or hallucinated (1).

## Sources

| File | Domain | Examples | Description |
|------|--------|----------|-------------|
| `backend/app/data/calc_all.jsonl` | Calculus | 180 | 60 problems × 3 answer variants each |
| `backend/app/data/algebra_hallucination_dataset.jsonl` | Algebra | 300 | 10 equations × 10 repetitions × 3 variants |
| **Combined** | Both | **480** | Merged + 80/20 stratified split |

## Schema

```json
{
  "id": "train_0001",
  "question": "Solve: Differentiate: d/dx (x^3)",
  "student_level": "Calculus",
  "model_answer": "d/dx(x^3)=3x^2 -> Answer: 3x^2",
  "label_hallucinated": 0,
  "error_type": "none",
  "severity": 0
}
```

| Field | Type | Values |
|-------|------|--------|
| `id` | string | Unique example identifier |
| `question` | string | Math question as posed to the AI |
| `student_level` | string | Pre-Algebra, Algebra I, Algebra II, Calculus |
| `model_answer` | string | The AI's response (correct or hallucinated) |
| `label_hallucinated` | int | 0 = correct, 1 = hallucinated |
| `error_type` | string | none, arithmetic, reasoning_gap, feedback |
| `severity` | int | 0–3 (0 = no error, 3 = most severe) |

## Error Taxonomy

| Error Type | Description | Example |
|------------|-------------|---------|
| `none` | Correct answer with valid reasoning | `d/dx(x^3) = 3x^2` |
| `arithmetic` | Correct method, wrong computation | `d/dx(x^3) = 2x^2` (power wrong) |
| `reasoning_gap` | Plausible but conceptually flawed | Claims "it should be X because it seems close" |
| `feedback` | User-submitted labels (for retraining) | Any |

## Calculus Breakdown (180 examples)

| Topic | Problems | Correct | Hallucinated |
|-------|----------|---------|-------------|
| Derivatives | 20 | 20 | 40 |
| Indefinite integrals | 20 | 20 | 40 |
| Limits | 20 | 20 | 40 |

Each problem has exactly 3 answer variants:
1. **Correct** — full step-by-step solution
2. **Arithmetic error** — wrong arithmetic, right method (severity 2)
3. **Reasoning gap** — confident but logically wrong (severity 3)

## Algebra Breakdown (300 examples)

10 base equations (linear, e.g. `2x + 5 = 17`) each repeated 10 times:
- 10 correct answers per equation (total 100)
- 10 arithmetic errors (+2 offset to claimed answer)
- 10 reasoning gaps (step errors)

## Train/Dev Split

Generated by `experiments/merge_datasets.py`:

| Split | Examples | Hallucinated | Correct | Ratio |
|-------|----------|-------------|---------|-------|
| Train | ~384 | ~256 | ~128 | 2:1 |
| Dev | ~96 | ~64 | ~32 | 2:1 |

Stratified by `label_hallucinated`, random seed 42 for reproducibility.

## Regenerating the Dataset

```bash
# Calculus examples
python backend/app/data/generate_calc_dataset.py

# Algebra examples
python generate_algebra_dataset.py

# Merge into train/dev
python experiments/merge_datasets.py
```

## Limitations

- Synthetically generated: distribution may differ from real AI tutoring outputs
- Only covers single-variable calculus and linear algebra
- Error types do not yet include: unit errors, conceptual formula misapplication, sign errors (partially covered via `sign_error_hint` feature)
- No human evaluation of whether the generated "hallucinations" represent realistic AI failure modes
